04 Philosophy

The non-authenticity axiom.

Why we refuse to build black-box authenticity certifications.

"PROOF should not pretend to certify that a document is authentic. It should show what it extracted, what it checked, what it found, and what it could not establish."

Document verification has been plagued by "magic-word marketing" — companies claiming proprietary neural networks can tell you whether a document is "100% genuine" or "fake". In reality, authentic invoices frequently contain layout quirks, and forged documents can be typed cleanly.

PROOF replaces faith with source evidence. Every calculation ($\text{Subtotal} + \text{Tax} = \text{Total}$), every PO cross-reference, and every date sequencing check is computed deterministically in transparent Python and JavaScript code, citing the exact document line and page number.
